# הפודקאסטים שלי

אפליקציית ווב (PWA) לתור פודקאסטים מיוטיוב. הניגון נפתח ב-YouTube Music.

## העלאה
1. צור repo חדש ב-GitHub (למשל `podcast-queue`) והעלה את כל הקבצים לשורש שלו.
2. Settings → Pages → Branch: main, תיקייה: / (root) → Save.
3. פתח את הכתובת בכרום באנדרואיד → ⋮ → "התקנת אפליקציה".

## שימוש
- ביוטיוב: שתף → "הפודקאסטים שלי". הפרק נכנס לתור.
- ▶ נגן פותח את הפרק באפליקציית YouTube Music.
- ✓ מסמן כנשמע. 🎲 בוחר פרק אקראי.
- הנתונים נשמרים בטלפון בלבד. בהגדרות (⚙︎) יש גיבוי ושחזור.
- רשות: מפתח YouTube Data API בהגדרות מוסיף אורך פרק וסינון לפי זמן.
